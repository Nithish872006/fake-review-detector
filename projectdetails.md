# FAKE PRODUCT REVIEW DETECTION USING MACHINE LEARNING

## Problem Statement

Online shopping websites contain many fake product reviews that mislead customers. It becomes difficult for users to identify genuine and fake reviews manually. This project helps to detect fake product reviews using Machine Learning techniques.

---

# Project Objectives

* To identify fake and genuine product reviews
* To improve customer trust in online shopping
* To automate review classification
* To reduce spam and misleading reviews

---

# Project Description

The Fake Product Review Detection System is a Machine Learning based web application used to classify reviews as fake or real. The user enters a product review through a webpage. The system analyzes the text using Natural Language Processing and predicts whether the review is fake or genuine.

---

# Advantages

* Fast detection of fake reviews
* Improves online shopping experience
* Reduces spam reviews
* Easy to use interface
* Automatic prediction system

# Algorithm Used

## Naive Bayes Algorithm

Naive Bayes is a Machine Learning algorithm used for text classification. It predicts whether a review is fake or real based on the words present in the review.
